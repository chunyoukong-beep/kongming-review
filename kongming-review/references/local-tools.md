# 本地视频取材

Python 3.10+。下述命令以 Skill 根目录为工作目录；视频、字幕、模型和输出参数使用真实绝对路径，并保留引号。输出目录必须尚不存在。脚本不访问网络、不收集密钥、不上传素材、不覆盖已有目录。

## 依赖

使用已有合适的 Python 环境，或在独立环境安装 `requirements.txt`。基础依赖为 Pillow 和 imageio-ffmpeg；系统有 FFmpeg 时优先使用系统版本。按宿主的安装权限执行，不修改用户全局 Python 配置。

```bash
python -m pip install -r requirements.txt
python scripts/doctor.py
python scripts/prepare_video.py --help
```

调用时提供 `--video` 原片路径、`--out` 新建证据目录。已有同版字幕提供 `--subtitles`，支持 UTF-8 SRT、VTT；字幕不是已核对的原声。

没有字幕时，可安装 `pywhispercpp>=1.5,<2`（本次验证1.5.1），并用 `--model` 指定已有的本地 Whisper GGML 模型文件。该选项仅接受本地文件，不会自动下载模型。需要模型时从 [whisper.cpp 官方模型说明](https://github.com/ggml-org/whisper.cpp/tree/master/models) 选择，说明下载大小及来源并遵循宿主授权。中文可用 large-v3-turbo 的合适量化版；速度与识别效果取决于设备、模型、口音和录音。

`--model` 与 `--subtitles` 二选一。未提供二者且有音轨时，会提取 `audio.wav` 并明确标为 `audio_not_transcribed`；应继续使用宿主转写能力或取得字幕后再审口播，不把空转写当成无风险。

## 输出与核对

- `evidence.json`：时长、音轨、帧位置、图册、逐句转写及覆盖限制。
- `contact-*.jpg`：每张12帧、附原片秒数；需用宿主图像能力实际查看。
- `frames/*.jpg`：需要放大核对的原始抽样图。
- `audio.wav`：有音轨时导出的单声道16kHz音频。
- `transcript.txt`：可读的带时间点文字。

默认开头3秒内每0.5秒取样，另结合全片场景变化及2秒间隔；最多96帧，超额时保留开头并在全片候选点中均匀取样。长视频的实际间隔会增大。`--max-frames` 可在12至240间调整；可用 `--interval` 加密到目标片段需要的密度，仍不宣称逐帧看懂。单文件上限60分钟。

脚本只准备证据，报告由当前 AI 宿主生成；宿主需要具备图像理解能力。音频理解是否可用另行判断。宿主为云端 AI 时，交给它的图册、文字或音频按其数据处理方式执行；本地取材不代表完整审片均在本地。

输出包含原片画面与转写，留在本机私有目录。准备公开 Skill 或提交代码时仅打包 Skill 文件，不加入取材目录、模型、视频、历史报告和凭据。

## 首次体验与片段预览

在 Skill 根目录运行 `python scripts/demo.py --out demo-output`。它生成显著标记的9秒无声合成图卡、示例字幕、取材结果及从3至6秒截取的候选片段。字幕为演示文字，不是识别出的口播。此演示只验证工具链，不证明AI判断或真实短视频表现。已有同名输出目录时需换名。

真实审片推荐了具体区间后，调用 `python scripts/export_clip.py`，提供原片 `--video`、来源起点秒数 `--start`、终点秒数 `--end` 和新的MP4文件名 `--out`。预览最长30秒，会重新编码并保留原片存在的首条音轨，不改变原片。导出附带 `.source.json`，记录原片路径与来源区间；该文件留在本地。

播放导出片段，核对语义和动作是否完整、声音及接回正文的方法是否成立。逐帧截取受原片帧率影响；HDR、色彩及母版输出需要专项处理，预览不承诺母版色彩一致。仅看到图册而听不到原声时，对声音与连续性仍应保留判断。

`doctor.py --model` 可检查转写依赖与本地模型文件是否备齐；它不读取模型内容或证明转写质量，仍须实际运行。缺少模型时可以导入已有字幕完成取材，AI审片还依赖宿主能力。
